2. Eğitmen notu

Sınıfa açılış ve aktarım dili

“Cache'e veri koymak kolay, doğru zamanda geçersiz kılmak zor. Ürün kataloğu örneğinde stale verinin kabul edilebilir süresini iş birimiyle konuşmadan TTL seçmeyeceğiz.”

Sorulabilecek sorular
  • Cache hit oranı tek başına cache başarısı mıdır?
  • Boş DB sonucunu cache'lemek ne zaman gerekir?
  • Bir milyon key aynı anda expire olursa ne olur?
Sınıf içi tuzaklar

Cache hit ratio yüksek olsa bile stale/security-sensitive data riski olabilir. TTL yoksa bellek sınırsız büyüyebilir. Negative caching kısa TTL ister. Write-behind veri kaybı/flush garantisi ve retry ile birlikte tasarlanmalıdır.

3. Kavramsal anlatım: neden → nedir → nasıl

Neden?

Ürün kataloğunda aynı ürün kaydı çok okunur, az değişir. Cache-aside DB yükünü düşürür; fakat ilk miss'te kaynak DB'ye gider ve yazma/invalidation sıralaması tutarlılığı etkiler.

Nedir?

Cache-aside: uygulama cache'i okur, miss'te kaynağı okuyup cache'e koyar. Write-through: yazma cache ve source ile senkron; write-behind: cache'e yazıp source'u asenkron güncelleme riski taşır. Stampede aynı key miss'inde çoklu DB isteği; penetration var olmayan key yoğunluğu; avalanche çoklu eşzamanlı expire/failure dalgasıdır.

Nasıl?

Python fonksiyonu key'i okur, JSON parse eder; miss'te demo source function, JSON set EX. TTL'ye jitter eklenebilir. Invalidation write sonrası DEL veya versioned key/event ile yapılır. Lab source DB yerine sabit demo fonksiyonu kullanır; production DB transaction'ı simüle etmez.

UZMAN NOTU · Üretim, performans ve güvenlik

Cache key auth/tenant/locale/schema boyutlarını doğru kapsamalı, PII/secret cache policy'si olmalı. Dogpile lock/single-flight, bounded DB concurrency, randomized TTL, stale-while-revalidate; negative cache ve rate limiting ayrı kontrollerdir. Write-through iki sistem arasında dağıtık transaction garantisi sağlamaz. Cache outage için fail-open/fail-closed kararı route ve risk bazlı verilmelidir.

4. Adım adım uygulama (Lab)

Her checkbox sayfa içi ilerleme içindir; durum kaydedilmez. Komutları verilen sırayla uygulayın. Kod bloklarının sağ üstündeki Kopyala düğmesi içeriği panoya alır.

from __future__ import annotations

import json
import os
import random
from typing import Any

import redis


def load_product_from_source(product_id: int) -> dict[str, Any]:
    # Lab stand-in; replace with a bounded database call in an application.
    return {"id": product_id, "name": "Kahve", "price_cents": 2499}


def get_product(client: redis.Redis, product_id: int) -> dict[str, Any]:
    key = f"catalog:product:{product_id}"
    cached = client.get(key)
    if cached is not None:
        return json.loads(cached)
    product = load_product_from_source(product_id)
    ttl = 300 + random.randint(0, 30)
    client.set(key, json.dumps(product), ex=ttl)
    return product


def main() -> None:
    client = redis.Redis.from_url(
        os.getenv("REDIS_URL", "redis://localhost:6379/0"),
        decode_responses=True,
        socket_connect_timeout=2,
        socket_timeout=2,
        max_connections=20,
    )
    try:
        product = get_product(client, 42)
        print("Product:", product)
        print("TTL:", client.ttl("catalog:product:42"))
        # Simulate a source update followed by cache invalidation.
        client.delete("catalog:product:42")
        print("Invalidated:", client.exists("catalog:product:42"))
    finally:
        client.close()


if __name__ == "__main__":
    main()

Cache hit GET; miss calls source stand-in then caches JSON; random TTL spreads expiration; invalidation follows the hypothetical source write. Print/Run Python File. Output contains product dict, positive TTL 300–330 and invalidated 0.

python cache_demo.py

PowerShell/macOS use same command once venv is active. `ModuleNotFoundError` means wrong interpreter or dependencies missing.

This is a design exercise; do not cache raw 500 errors or authorization failures as “not found.”

5. Beklenen çıktılar

Output `Product: {'id': 42, ...}`, TTL integer 300–330, then `Invalidated: 0`. Second run after invalidation is a cache miss again.
