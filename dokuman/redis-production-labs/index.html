Ortak Redis key sözlüğü

Key’ler küçük harf, iki nokta ile ayrılmış ad alanları kullanır. Kullanıcıya göre ayrımda e-posta/Username değil JWT’den alınan userId kullanılır. TTL, veri yaşam döngüsünün parçasıdır; TTL kesin fiziksel silinme zamanı değildir.

Nasıl ilerlenir?

  1. Project analysis ile doğrulanmış mevcut davranışı öğrenin.
  2. Modülde “Mevcut projeden doğrulandı” ve “Önerilen geliştirme” ayrımına dikkat edin.
  3. Komut laboratuvarını docker exec -it redis-lab redis-cli ile deneyin.
  4. Kod örneklerini üretime kopyalamadan önce yapılandırma, test, yetkilendirme, gözlemlenebilirlik ve hata politikasını uyarlayın.
